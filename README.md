# parallelleaf.com

Static site for Parallel Leaf LLC, served by GitHub Pages at https://parallelleaf.com.

- `index.html`: landing page
- `privacy.html`: website privacy policy
- `style.css`: shared styles
- `fonts/`: Urbanist (SIL Open Font License, see `fonts/OFL.txt`), self-hosted so no third party sees visitors' IP addresses
- `CNAME`: custom domain for GitHub Pages
